# 惠州市考试工作日程系统

面向惠州市考试中心的工作日程协作系统。输入考试类型和考试日期，自动倒推全部考务工作节点，支持多人协作、管理员统筹、手机日历同步。

纯静态网页，可免费部署在 GitHub Pages；数据存储在 Supabase（免费额度）。

---

## 一、功能一览

| 模块 | 说明 |
|---|---|
| 账号登录 | 邮箱 + 密码注册登录；注册需邀请码；管理员可停用账号、调整角色 |
| 我的日程 | 我创建的、共享给我的日程；卡片显示倒计时和完成进度 |
| 新建日程 | 选考试类型（高考/中考/学考/自考/成考/教资笔试/教资面试/公务员/自定义）自动生成 12–28 个工作节点，可增删改 |
| 协同同事 | 创建时勾选同事；同事在「待办日程」看到该日程，可打勾、写备注；**日程内容只有创建者（和管理员）能改** |
| 待办日程 | 汇总所有与我相关的事项，按「已逾期 / 今天 / 7 天内 / 以后」分组 |
| 手机日历 | 一键导出 `.ics`，iPhone、安卓（Google/华为/小米日历）均可导入，每项工作提前 1 天提醒 |
| 管理中心 | 查看全部用户日程、共享日程、用户管理、模板库发布、操作日志、数据备份导出 |
| 模板库 | 内置 9 套考试流程模板 + 管理员发布的中心标准模板 |
| 导出 | CSV（Excel 可打开）、打印（纸质版表格） |

## 三、部署步骤（约 15 分钟）

### 第 1 步：创建 Supabase 项目

1. 打开 https://supabase.com ，用邮箱注册（免费）。
2. 新建项目：名称填 `huizhou-exam`，区域选 Singapore（离国内较近），设置数据库密码（记下即可，本系统不直接用）。
3. 等待约 2 分钟项目初始化完成。

### 第 2 步：建表

1. 左侧菜单进入 **SQL Editor** → **New query**。
2. 打开 `supabase/schema.sql`，全选复制，粘贴进去，点 **Run**。
3. 看到 `Success` 即完成。表、权限策略、触发器都已建好。

### 第 3 步：关闭邮箱验证（推荐，方便同事注册）

**Authentication → Providers → Email**：
- 把 **Confirm email** 关闭（关闭后注册即可直接登录）。
- 如果单位邮箱收不到验证邮件，这一步必须关闭。

### 第 4 步：填写配置

**Project Settings → API**，复制两个值：
- `Project URL`（形如 `https://xxxx.supabase.co`）
- `anon public` key（很长的一串）

打开 `js/config.js`：

```js
window.APP_CONFIG = {
  SUPABASE_URL: 'https://xxxx.supabase.co',
  SUPABASE_ANON_KEY: 'eyJhbGciOi...',
  INVITE_CODE: 'HZKS2026',        // 改成自己单位的邀请码
  ORG_NAME: '惠州市考试中心'
};
```

> 留空即为「本地演示模式」，界面可先试用，数据只存在本机浏览器。

### 第 5 步：发布到 GitHub Pages

1. 注册/登录 GitHub，新建仓库（Public 或 Private 均可，Pages 需要 Public 或付费）。
2. 把整个 `exam-work-schedule` 文件夹的内容上传到仓库根目录（网页上直接拖拽上传即可）。
3. 仓库 **Settings → Pages**：Source 选 `Deploy from a branch`，Branch 选 `main`、目录 `/ (root)`，保存。
4. 约 1 分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

### 第 6 步：创建管理员账号

1. 打开网页，点「注册」，**第一个注册的账号自动成为管理员**。
2. 把邀请码发给同事，让他们自行注册。
3. 管理员进入「管理中心」可停用离职人员账号、调整他人为管理员。

## 四、手机日历导入方法

在日程详情页点 **「📲 导入手机日历」**，会下载一个 `.ics` 文件。

**iPhone / iPad**
1. 用 Safari 打开网页并下载文件。
2. 打开「文件」App → 下载项 → 点该 `.ics` 文件。
3. 弹出「添加到日历」→ 选择日历账户 → 添加完成。
4. 每项工作会在**前 1 天**提醒（考试当天事项提前 2 天）。

**安卓（Google 日历）**
1. 下载 `.ics` 文件。
2. 电脑上打开 https://calendar.google.com → 设置 → 导入和导出 → 导入 → 选择文件。
3. 或在手机装「日历导入」类 App，直接打开 `.ics` 文件。

**华为 / 小米 / OPPO 日历**
- 文件管理 → 找到 `.ics` → 用「日历」打开 → 确认导入。

## 五、权限设计（与需求对应）

| 角色 | 能做什么 |
|---|---|
| 创建者 | 编辑/删除日程、增删工作事项、调整共享人员、打勾、写备注 |
| 被共享的同事 | 在待办日程中看到该日程、打勾标记完成、写自己的备注；**不能修改日程内容** |
| 管理员 | 查看全部用户日程、把任意日程共享给他人、停用账号、设置管理员、发布模板、查看日志、导出备份 |

打勾进度是**每人独立**的：创建者可以看到每位同事完成了多少项，互不覆盖。

## 六、使用与安全建议

1. **数据范围**：本系统只放工作安排（会议、布置考场、报送材料等），不要录入考生个人信息、试题内容等涉密信息。
2. **邀请码**：`config.js` 里的邀请码只是前端校验，真正的防线是「管理员停用账号」。发现陌生注册，进管理中心停用即可。
3. **备份**：管理员每月点一次「导出全部数据」，保存 JSON 文件到单位内网或移动硬盘。
4. **首次使用建议**：先由 1–2 人用「本地演示模式」熟悉流程，再正式上云。
